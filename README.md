# calculadora em react

projeto feito em sala de aula, com bastante javascript, que reúne vários tipos de cálculo em um só lugar.

## acesse online
https://calculadora-js-edn1.onrender.com

## funcionalidades
- tela inicial (home)
- cálculo de celsius
- cálculo escolar
- cálculos de matemática
- cálculo de metros
- sequência
- cálculo de tinta

## estrutura
o projeto é dividido em páginas e componentes reutilizáveis:
- card: organiza e apresenta cada calculadora
- header: cabeçalho com a navegação entre as telas
- results: mostra o resultado dos cálculos
- uma página para cada tipo de cálculo

## o que aprendi
- como criar e reutilizar componentes em react
- como escrever a lógica dos cálculos em javascript
- como organizar várias calculadoras em páginas diferentes
- como mostrar o resultado de forma separada em um componente
- como colocar um projeto online
